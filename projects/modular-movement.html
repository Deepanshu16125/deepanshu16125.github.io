Modular Movement

A skill-showcase project: an animated 3D character who can run, sprint, jump and crouch, with a small environment to move around in.

How it was built
  1. Unity 6 and C#, built around a state machine: an IPlayerState interface with Idle, Moving, Sprinting and Jumping states, switched by a PlayerStateMachine.
  2. Rigidbody physics-based movement with a ground check; input from Unity’s New Input System, with sprint on Shift.
  3. A rigged character driven by an Animator: a Blend Tree for idle, walk and sprint, plus a Jump state.
  4. Modular design: each movement state is its own class, so abilities can be added or tuned independently.
