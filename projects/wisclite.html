WiscLite

A Rust LSM-tree key-value store that separates keys from values, after the WiscKey paper (USENIX FAST ’16), with an inline-value baseline mode to measure the difference.

  1. Values are appended once to a checksummed value log; the LSM-tree keeps only key → (offset, length) pointers.
  2. WAL with crash recovery, sorted SSTables with Bloom filters, size-tiered compaction, value-log GC and an atomic MANIFEST as the commit point.
  3. In the 500,000-put benchmark, write amplification was 1.16× versus 4.55× for the inline baseline; range scans are slower, the paper’s known cost.
  4. The site runs the actual Rust engine compiled to WebAssembly: an interactive Try-it console that demonstrates a crash and WAL replay, an in-browser benchmark, and sliders that estimate write amplification.
  5. CLI plus a localhost HTTP server with a JSON API and a metrics dashboard.
  6. 22 tests covering storage, crash recovery, compaction, GC and the HTTP API; the README lists the limitations openly.
