CodeCage

A Rust sandbox that runs untrusted WebAssembly plugins under strict, deny-by-default limits.

  1. Deny-by-default: plugins get no file, environment or network access.
  2. Fuel, memory, timeout and output limits, with per-plugin TOML policies, SHA-256 hash pinning and an audit log.
  3. Live HTML/JS dashboard for running plugins and reading results.
  4. 14 plugins in Rust and C (10 attacks, all contained); 26 tests, 19/19 scenarios, CI on Windows and Linux; v1.0.
  5. 1.43× native speed, ~5.5% fuel cost, and a compile cache that makes start-up 3× faster (28.5 → 9.4 ms).
